Sistema de Tarefas (CLI)

Python Estruturas de Dados Modularidade

O Desafio

Criar uma aplicação de linha de comando robusta para gerenciamento de fluxo de trabalho, aplicando conceitos de persistência temporária e menus interativos sem dependências de interfaces gráficas pesadas.

Decisões Técnicas

Decomposição do sistema em camadas bem definidas. Lógica de negócios isolada das funções de apresentação no terminal, utilizando estruturas de dicionários para indexação veloz de estados.

Aprendizados

Tratamento rigoroso de exceções para inputs de usuário inválidos e domínio sobre loops de eventos (event loops) estruturados na CLI.

Página Temática de RPG

HTML Semântico CSS Avançado UI Design

O Desafio

Construir uma landing page imersiva inspirada no universo de Dungeons & Dragons, traduzindo estéticas medievais clássicas para componentes modernos da web sem prejudicar a acessibilidade.

Decisões Técnicas

Uso extensivo de variáveis nativas do CSS (CSS Variables) para controle de paletas complexas de alto contraste, fontes serifadas otimizadas para leitura e marcação estritamente estruturada.

Aprendizados

Técnicas avançadas de estilização temática, manipulação de opacidade em camadas visuais e aplicação prática de tags semânticas para melhorar a indexação e leitores de tela.
