## Descrição do Projeto

Este projeto consiste em um portfólio pessoal desenvolvido utilizando apenas HTML5 e CSS3.

O objetivo do site é apresentar informações profissionais, habilidades técnicas e projetos desenvolvidos durante os estudos em programação e desenvolvimento web.

O portfólio possui foco em design simples e que seja de fácil entendimento, com responsividade e organização semântica, trazendo uma identidade visual inspirada no universo da programação.

---

## Funcionalidades do Site

- Página inicial com apresentação pessoal;
- Seção sobre mim;
- Exibição de habilidades técnicas;
- Cards de projetos;
- Página de contato;
- Layout responsivo para dispositivos móveis;
- Navegação entre páginas.

---

## Principais Desafios Encontrados

- Desenvolver um layout totalmente responsivo sem utilizar frameworks(Tailwind, React etc.);
- Organizar o conteúdo utilizando HTML semântico;
- Criar uma identidade visual moderna utilizando apenas HTML e CSS puro;
- Padronizar o tamanho das imagens e cards dos projetos;
- Estruturar a navegação entre as páginas do portfólio.
- Proporcionar uma experiência agradável para quem acessar o site, mesmo em dispositivos diferentes(celular, computador etc.)

## Considerações Finais

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de desenvolvimento front-end, incluindo semântica HTML, estilização com CSS e criação de layouts responsivos. Foi uma experiência engrandecedora para qualquer aluno que busca aprimorar suas habilidades com front-end, além de proporcionar um desafio formidável, mesmo para aqueles com contato prévio com as tecnologias citadas acima.

O portfólio também serviu como prática de versionamento utilizando Git e hospedagem com GitHub Pages.
